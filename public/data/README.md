# Hospital GeoJSON Data

Place OpenStreetMap hospital extracts here. Run `scripts/extract_hospitals.py` to generate files.

## Required files

| File | Country | Status |
|------|---------|--------|
| `hospitals_togo.geojson` | Togo | ✅ Sample included (5 hospitals for demo) |
| `hospitals_nigeria.geojson` | Nigeria | ⬜ **You must add** |
| `hospitals_ghana.geojson` | Ghana | ⬜ **You must add** |
| `hospitals_benin.geojson` | Benin | ⬜ **You must add** |
| `hospitals_cote_divoire.geojson` | Côte d'Ivoire | ⬜ **You must add** |

## Format

See `prompt.md` section 8.5 for the GeoJSON schema.

Coordinates: `[longitude, latitude]` (GeoJSON standard).
